# X-Ray Forge

Мастерская моддинга **S.T.A.L.K.E.R.** для проектов на движке X-Ray: редактор диалогов,
персонажей, предметов, иконок, скриптов, локализаций и квестов. Поддерживает «Тень Чернобыля»
(SoC), «Чистое Небо» (CS) и «Зов Припяти» (CoP).

Приложение — **WPF (.NET 9)** в каталоге `dotnet/`. Прежний клиент Electron + React удалён:
его функции перенесены в WPF, карта соответствия модулей сохранена в `MIGRATION.md` (§4).

## Требования

- Windows 10/11 x64;
- .NET SDK **9.0** (`dotnet --version`).

## Сборка, запуск, тесты

```powershell
dotnet build dotnet/XRayForge.sln -c Debug
dotnet run --project dotnet/src/XRayForge/XRayForge.csproj

# проверка перед коммитом
dotnet build dotnet/XRayForge.sln -c Release
dotnet test  dotnet/XRayForge.sln -c Debug
dotnet test  dotnet/XRayForge.sln -c Release

# одиночный exe (framework-dependent, win-x64) → dotnet/artifacts/win-x64
dotnet/publish.ps1
```

## Возможности

### Проекты и данные

- Окно приветствия: создание, открытие, переименование и удаление проектов, история бэкапов.
- Раздельные **название проекта** и **ID диалога** (`dialogueId`): по нему формируются `id`
  реплик (`<id>_1`, `<id>_2`, …) и имена файлов экспорта.
- Настройки проекта (название, ID, серия, папки `gamedata`/ресурсов, кодировки импорта и
  экспорта) и настройки программы (тема, показ текста на узлах, интервал автосохранения,
  ширины панелей).
- Выбор серии игры (SoC / CS / CoP) — влияет на пути экспорта (`config` либо `configs`).
- Импорт и экспорт `.project.json`, автосохранение с настраиваемым интервалом; профиль
  программы и текущий проект хранятся в `%APPDATA%\XRayForge`.
- Сканирование `gamedata`: автоопределение типа файлов (`.xml`, `.ltx`, `.script`, `.lua`,
  `.dds`) и кодировки (BOM, XML-декларация, UTF-8, Windows-1251), прогресс, пропуск
  повреждённых файлов, восстановление данных при повторном открытии проекта.
- Снимок каталога `gamedata` (`catalog.csv`) используется для автодополнения путей, даже если
  папка игры не открыта.

### Вкладки

| Вкладка | Возможности |
|---|---|
| **Диалоги** | Граф реплик: узлы, связи, ветвления, проверки условий, перетаскивание, валидация `text_id`, экспорт `game_dialogs*.xml` и `dialogs.ltx`, игровой ZIP. |
| **Персонажи** | `character_desc_*.xml`: сообщества, ранги, отношения, биография, диалоги, `supplies`, экспорт в `config(s)/gameplay`. |
| **Предметы** | LTX-наследование (`items.ltx`, `weapons.ltx`, `ammo.ltx`, …), категории, стоимость и параметры, экспорт CSV и обратная раскладка по файлам. |
| **Иконки** | Атлас DDS (DXT1/3/5, BC4/BC5): сетка, ячейки, привязка к предметам, импорт/экспорт PNG и DDS. |
| **Скрипты** | Редактор Lua: подсветка, токенизация, баланс блоков, сниппеты, автодополнение, переход по вызовам, undo/redo. |
| **system.ltx** | Секции и параметры, дерево и SVG `#include`, создание инклюдов. |
| **Языки** | `string_table` по локалям: таблицы, сводная таблица, счётчики использования `text_id` в репликах, LTX, скриптах, квестах и персонажах. |
| **Квесты** | `game_tasks`/`task_manager`: квесты, цепочки, `condlist`, дерево и SVG-схема. |
| **Обзор** | Сводка проекта, игровой ZIP (`*_gamedata.zip`), самопроверка `ProjectSelfCheck` в отдельном окне. |

### Интерфейс

- Тёмная и светлая темы, акцентные состояния вкладок, единая типографика и контролы.
- Локализация RU/EN (RU — основной язык); все строки — ключи `LocalizationService`.
- Горячие клавиши `Ctrl+1…9` для вкладок, изменяемая ширина боковых панелей (сохраняется в
  настройках), пустые состояния и статусная палитра.

## Структура решения

```
dotnet/
├─ XRayForge.sln
├─ publish.ps1
├─ src/XRayForge.Core/     net9.0 — чистая логика без WPF
├─ src/XRayForge/          net9.0-windows — WPF + CommunityToolkit.Mvvm
├─ tests/XRayForge.Tests/  xUnit
└─ docs/                   FEATURE_GAP_AMK.md, CODE_REVIEW.md, UI_WINDOWS_TAB.md
```

Документация:

- `MIGRATION.md` — прогресс миграции, решения этапов, отклонения и число тестов;
- `dotnet/docs/FEATURE_GAP_AMK.md` — что осталось относительно целевого набора функций;
- `dotnet/docs/CODE_REVIEW.md` — техническое ревью модулей Core и WPF;
- `dotnet/docs/UI_WINDOWS_TAB.md` — план вкладки UI-окон (`config/ui`).

## Ограничения

- Не поддерживаются Level Editor, 3D-рендер, погода, освещение и шейдеры — это остаётся
  внешним инструментам (SDK, Photoshop/GIMP, Blender).
- Предпросмотр UI-окон показывает геометрию и подписи; DDS-текстуры и шрифты движка не
  рендерятся.
- Плагины-экспортёры прежнего клиента (`new Function`) не перенесены: см. риски в
  `MIGRATION.md` §5.
