# X-Ray Forge

Мастерская моддинга **S.T.A.L.K.E.R.** для проектов на движке X-Ray: редактор диалогов,
персонажей, предметов, иконок, скриптов и локализаций. Поддерживает «Тень Чернобыля» (SoC),
«Чистое Небо» (CS) и «Зов Припяти» (CoP). Работает в браузере и как настольное
приложение (Electron, сборки portable/NSIS для Windows).

## Возможности

### Управление проектами

- Окно приветствия при запуске: создание, открытие, переименование и удаление проектов.
- Раздельные **название проекта** и **ID диалога** (`dialogueId`), по которому формируются
  `id` реплик (`<id>_1`, `<id>_2`, …) и пути экспорта.
- Раздельные **настройки проекта** (название, ID диалога, серия, папки gamedata, кодировки)
  и **настройки программы** (тема, отображение текста/id на узлах, интервал автосохранения).
- Выбор серии игры (SoC / CS / CoP) — влияет на пути экспорта (`config` либо `configs`).
- Импорт/экспорт проекта в `.project.json`; автосохранение с настраиваемым интервалом
  (в браузере — `localStorage`, в Electron — дополнительно файл в папке `saves/`).

### Сканирование `gamedata`

- Выбор папки `gamedata` через кнопку в настройках проекта (File System Access API) — папка
  сканируется сразу при выборе; отдельные кнопки «Сканировать gamedata» убраны.
- Автоопределение типа файлов: `.xml`, `.ltx`, `.script`, `.lua`, `.dds`.
- Автоопределение кодировки: BOM, XML-декларация `encoding`, UTF-8 и Windows-1251.
- Прогресс-бар загрузки; повреждённые файлы пропускаются (счётчик «пропущено»).
- Память о папках gamedata и ресурсов; при открытии проекта данные восстанавливаются,
  при отсутствии — предложение перевыбрать папку.
- Предметы подгружаются из разных файлов (`items.ltx`, `weapons.ltx`, `ammo.ltx`,
  `outfit.ltx`, `artefacts.ltx`, `detectors.ltx`, `quest_items.ltx` и т.д.) и группируются
  по исходному файлу.

### Редактор диалогов (граф)

- Визуальный граф: Старт, Реплика, Случайный выбор, Конец (проверочные узлы и «действие»
  убраны из палитры — они задаются метаданными реплики).
- Импорт `game_dialogs` (`game_dialogs > dialog > phrase_list > phrase`), несколько диалогов
  в одном XML; повторяющиеся `phrase id` сохраняются как отдельные узлы.
- Роль реплики (NPC / ГГ / не определено) выбирается вручную; поле `speaker` не экспортируется.
- Метаданные: `has_info`, `dont_has_info`, `precondition`, `give_info`, `disable_info`, `action`
  (сворачиваемый блок «Действия и условия»).
- Валидация: битые связи, дубли ID, импортированные циклы (предупреждения).
- Отображение **текста вместо id** на узлах (переключается в настройках программы).
- Навигация: мини-карта, «в центр», авто-раскладка, подсветка связей, **рамка выделения**
  (`Shift`+перетаскивание) и групповое перемещение, сворачиваемые панели и полноэкранный холст.
- Экспорт в игровой XML/ZIP и внутренний XML редактора.

### Персонажи

- Импорт `specific_character` из `character_desc_*.xml` (все поля: name, community, rank, bio,
  icon, visual, start_dialog, actor_dialog).
- Группировка по `community` с иконками, поиск, подсветка дубликатов id.
- Связь с диалогами (по `start_dialog`/`actor_dialog`) и «автосвязь».
- Просмотр исходного XML персонажа.

### Предметы

- Редактор `items.ltx` с наследованием LTX: унаследованные поля заблокированы (🔒, с указанием
  родителя), разблокировка с подтверждением.
- Отмена/повтор структурных изменений, поиск (по имени и значениям полей), категории
  (оружие, боеприпасы, броня, артефакты, юзабельные, детекторы, апгрейды, квестовое, …).
- Симуляция слотов экипировки (оружие, броня, шлем для CoP) с иконками из атласа.
- Экспорт таблицы предметов в CSV.

### Иконки и атласы

- Декодер DDS: DXT1/DXT3/DXT5 и несжатые 24/32-битные; **экспорт обратно в DDS (DXT1)**.
- Выделение области мышью, зум (`Ctrl+колесо`) и панорамирование (средняя кнопка).
- Сравнение двух атласов наложением, не-квадратные ячейки, пресеты, горячие клавиши
  (стрелки, Enter — закрепить, Ctrl+Z/Y).
- Коллекции избранных иконок, экспорт спрайт-листа, поиск дубликатов, копирование/вставка
  иконок, создание пустого атласа.

### Скрипты

- Редактирование `.script`/`.lua` с номерами строк и проверкой баланса скобок.
- Поиск по скриптам, переименование/удаление файлов, сниппеты (`function`, `if/then`, `for`,
  `while`, `local`), список функций.
- Режим просмотра с подсветкой синтаксиса и сворачиванием блоков.

### system.ltx и инклюды

- Редактирование `system.ltx`; автоподстановка `#include` из загруженных файлов.
- Список подключений с подсветкой битых и комментированием строк; открытие файла по клику.
- Дерево инклюдов с проверкой циклов и список уникальных секций.

### Языки (string_table)

- Импорт `string_table` из `gamedata/config(s)/text/<locale>/...`, группировка по локали.
- Редактирование переводов по `text_id` (с контекстом — в скольких репликах используется),
  подсветка пустых переводов и дубликатов id, ручная привязка локали.
- Сводная таблица: правка всех локалей одновременно (колонки по локали).

### Экспорт

- Игровой ZIP: `dialogs_*.xml` плюс отдельный XML `string_table` для каждого языка.
- Кодировка декларации и байтов совпадает: Windows-1251 либо UTF-8.
- Внутренний XML редактора, проект в `.project.json`, DDS и PNG иконок.

### Самопроверка

- Встроенные тесты: парсинг LTX и include, валидация графа, декодирование Windows-1251,
  локализации, предметы и координаты иконок.

## Установка и запуск

```bash
npm install
npm run start      # веб-версия (Vite dev-сервер)
npm run build      # сборка веб-версии
npm run electron   # запуск в Electron-оболочке
npm run dist       # сборка Windows (portable + NSIS)
npm test           # юнит-тесты
```

## Стек

- React 18, Vite 5, Tailwind CSS.
- `fflate` (ZIP), `@xmldom/xmldom` (тесты).
- Electron 31 + electron-builder.

## Ограничения

Экспорт сохраняет игровые `phraseId`, `next` и metadata. Технические узлы редактора вне
`PHRASE` не являются полным компилятором всех возможных сценариев X-Ray. Перед подключением
результата в конкретный мод проверьте требуемые `include` и регистрацию диалога в его
конфигурации. Предпросмотр 3D-моделей персонажей (`visual`) не поддерживается — он требует
игровых ассетов (OGF/текстуры) и WebGL-рендера.
