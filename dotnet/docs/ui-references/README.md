# UI-референсы (скриншоты и шрифты)

Папка для референсов интерфейса, по которым воссоздаётся UI WPF-версии
X-Ray Forge (этапы 5–7 миграции).

## Структура

- `screenshots/` — скриншоты интерфейса (`.png`, `.jpg`, `.webp`).
- `fonts/` — файлы шрифтов (`.ttf`, `.otf`/`.ttc`) + `LICENSE` каждого шрифта.
- `tokens/` — извлечённые палитры/размеры (текстовые файлы, `*.tokens.md`).

## Как добавлять скриншоты

1. Положите файл в `screenshots/`.
2. Имя в формате `NN_<экран>_<тема>.png`, например:
   - `01_welcome_dark.png`
   - `02_dialogs_editor_dark.png`
   - `03_items_light.png`
3. Добавьте строку в «Реестр референсов» ниже (опционально — пояснение).

## Что извлекается из скриншота

- иерархия и сетка layout (сайдбар, хедер, панели, тулбары);
- размеры/отступы (в DIP, приближённо), радиусы скруглений;
- палитра (фоновые/акцентные/текстовые цвета) — сэмплирование пикселей;
- типографика (кегль, вес, трекинг), иконографика;
- состояния компонентов (обычный/наведён/активен/выделен/неактивен).

## Шрифты

- Предпочтение — свободные лицензии (OFL / Apache 2.0), файл лицензии кладём рядом.
- Скачивание — по прямым URL через `Invoke-WebRequest`; URL фиксируем в реестре.
- Для иконочных шрифтов возможна NuGet-упаковка (например, `MahApps.Metro.IconPacks`).
- В WPF шрифты подключаются как `Resource` и используются через `FontFamily`.

## Порядок работы

1. Скриншоты → `screenshots/` (имя `NN_<экран>_<тема>.png`).
2. Шрифты → `fonts/` (+ `LICENSE`), URL в «Реестре шрифтов».
3. Из палитры/размеров формируются токены в `tokens/`.
4. Токены превращаются в `ResourceDictionary` (`Colors.xaml`, `Typography.xaml`,
   `Controls.xaml`) и применяются в `MainWindow` и вкладках (этапы 5–7).
